# 간단한 채팅 서버 예제

이 디렉터리에는 TCP 기반 채팅 서버 예제(`chat_server.py`)가 포함되어 있습니다. 클라이언트는 텔넷 등을 이용해 접속할 수 있으며, 다음과 같은 간단한 명령을 지원합니다.

```
USERNAME <사용자명>     # 접속 후 첫 메시지로 사용자명 전송
MSG <메시지>            # 전체 사용자에게 메시지 전송
CARD <금액>             # 카드 결제 후 포인트 충전 (1원당 1C)
CASH <금액>             # 현금 결제 후 포인트 충전 (1원당 1C)
BALANCE                 # 현재 포인트 잔액 확인
QUIT                    # 접속 종료
```

결제 연동 기능은 구현되어 있지 않으며, 금액을 입력하면 즉시 포인트로 전환됩니다. 포인트 잔액은 서버가 실행되는 동안 메모리에 저장됩니다.

## 실행 방법

```bash
python3 chat_server.py
```

서버는 기본적으로 포트 `9009`에서 실행됩니다. 클라이언트는 텔넷 등으로 해당 포트에 접속하여 명령을 입력할 수 있습니다.
